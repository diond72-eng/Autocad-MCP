# Prototype and issue workflow

Establish the project datum, dimensions and scope. Inventory the supplier
carcass and fronts, cut thicknesses, backs, plinths, shelves, door profiles,
fittings, service cavities and connection clearances independently. Track
unverified geometry by part and record each release hold.

Audit the input drawings. If external reference PDFs are supplied, measure
their actual font cap heights, stroke widths, hatches, ticks, sheet margins
and scale. Keep commercial artwork, titles and source construction
specifications private. Apply the professional profile unless an alternative
is requested.

Before batch production plot a representative plan/elevation, a cabinet
section intersecting the true body, and an enlarged fabricated junction.
Use 300 dpi matched-page proofs, then inspect detail crops for clipped views,
tight witness lines, reversed orientation, missing panels and readability.
Correct the geometry and repeat, retaining review findings with the issue.

For cabinet work show individual adjacent carcass sides, backing thickness
and service offsets, finished versus internal elevations, visible, cut and
hidden linework, and plinth and foot construction. Check appliance bays,
verified sink templates, sink rail interference and electrical access. Use
dimension chains from a stable datum, rather than unverified size overrides.

Audit the reopened file, dimension geometry and scales. Compare PDF signatures
with the relevant baseline and inspect differences. A screenshot or regression
pass cannot replace trade judgment. Package native drawings, vector plans,
schedules, QA results, revision history and explicitly assigned release holds.
