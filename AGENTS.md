# Repository instructions

Use the [professional-cad skill](skills/professional-cad/SKILL.md) for drafting tasks.
Use the Linux headless ezdxf backend and the versioned professional drafting
profile. Preserve upstream server behavior and native CAD entities. Model
individual physical components and derive all views and schedules from shared
parameters. Record confirmed dimensions and provisional construction assumptions.

Before delivering CAD, audit and reopen every drawing, verify measured
dimensions, generate vector PDFs, render and inspect every sheet at 300 dpi,
compare representative plots and correct clipping or overlaps. Report capability
limits and never mark unverified drawings approved for manufacture. Run the
professional CAD regression tests after changes to drafting functions or assets.
Avoid silent changes to fonts, plot treatment, or the golden fixture. Keep
private source drawings, supplier material and credential data outside Git.
