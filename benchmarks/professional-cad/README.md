# professional-cad-v1.0 benchmark

The user-accepted private golden master is the unmodified Rev 06 package, SHA-256
`f0dacd6baa63deacc6c5432e5c539acbba9537d947071ff0c0fe75beb572c4a8`.
It is held outside this public fork. It contains 15 landscape A3 vector sheets,
146 measured dimensions, 46 locked viewports and 663 tagged CAD components.
It is neither a public fixture nor build input.

The private local snapshot additionally holds the full working source, original
inputs, source PDF analyses, 300 dpi crops, plot configuration, MCP operation
records, ODA distributions and checksums, OS and both Python package manifests.
Public examples use fictitious room geometry and identifiers.

The public baseline tests prevent permission or visual style changes from
silently altering the anonymised fixture. A private benchmark owner can run the
private source engine and the public comparison command on the same source
drawings. The generic demonstration engine is a separate implementation,
so the private regeneration proves environment reproducibility, not that the
generic engine can replace every project-specific Rev 06 detail.
