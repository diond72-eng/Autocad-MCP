# Capability and limitation register

| Capability | Status |
|---|---|
| CLI and Linux plotting | Native DXF, A3 vector PDF, individual sheets and 300 dpi review images |
| Geometry | Parameterised axis-aligned bodies, sides, backs, shelves/pins, doors, Shaker rails and stiles, drawers and runners, feet, plinths, provisional hardware meshes |
| Joinery family inputs | Base, overhead, pantry, drawer, sink, appliance, open, credenza, wardrobe, locker, vanity, rectilinear island and custom rectilinear assembly |
| Views | Plan, finished/internal elevations, one computed section and detail with assembly axon. Lower-level section, rear-elevation and exploded projection primitives exposed |
| Electrical/hydraulic | Dimensioned room with equipment stations and schedules. Routing, compliance, load and connection design remain project-specific |
| Advanced fabrication | Corner geometry, arbitrary rotation/curved forms, profile-specific mechanical hardware, automatic fabrication detailing and comprehensive hidden-surface removal remain extension points |
| Architecture and construction | Room plans and shared sheet primitives. Full building, structural and mechanical disciplines are extension points |
| Drawing quality | Designed for review and project-specific development. Automated path, geometry and dimension validation does not certify commercial shop issue parity |
| Private Rev 06 regression | Original reference remains immutable. Reproduced with its snapshot sources, not ported to the generic project mapper |
| Native conversion | Optional ODA round trip. DXF is the default native editable template and drawing. Desktop DWT authoring is outside the Linux engine |
| Codex plugin | Local manifest provided. CLI and repo discovery used in Cloud. Browser plugin installation not validated |
